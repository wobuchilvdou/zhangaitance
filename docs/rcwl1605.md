# RCWL-1605 引脚与模式确认

依据实拍照片（正面丝印、背面 M1/M2 选择表）确认：

## 引脚（4 针，从 Vcc 一侧数起）

| 序号 | 丝印 | GPIO 模式含义 | 其他模式复用 |
|---|---|---|---|
| 1 | Vcc | 电源 5V | - |
| 2 | Trig_RX_SCL_I/O | 触发输入 | UART RX / I2C SCL / 1-Wire I/O |
| 3 | Echo_TX_RXON | 回波输出（高电平时长 = 声波往返时间） | UART TX / 1-Wire RXON |
| 4 | GND | 地 | - |

## 模式选择（背面 M1/M2 焊盘）

| M1 | M2 | 模式 |
|---|---|---|
| 0 | 0 | GPIO（默认出厂状态，待实测确认焊盘未焊） |
| 0 | 1 | IIC |
| 1 | 0 | UART |
| 1 | 1 | 1-Wire |

## GPIO 模式测距协议

1. Trig 拉高 ≥10 µs 后拉低，模块发射 8 个 40 kHz 脉冲。
2. Echo 引脚输出高电平，持续时间为声波往返时间。
3. 距离 cm ≈ Echo 高电平时间 µs × 0.0343 ÷ 2。
4. 需记录实测超时、量程和刷新率；当前模块精度不佳，后续计划更换。

## 仍未确认（阻塞硬件驱动定稿）

- Trig/Echo 实际接 ESP32 GPIO5/GPIO18（沿用此前接线，见 wiring.md），恢复接线后需通断确认。
- 背面 M1/M2 焊盘当前状态（是否保持默认 GPIO 模式）。
- 模块实测量程、盲区、刷新率与精度。
