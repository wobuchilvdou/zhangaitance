# 阈值配置草案

所有阈值必须实测校准。下面只列参数名，不写默认值。

| 参数 | 说明 | 状态 |
|---|---|---|
| distance_close_cm | 近距离障碍阈值 | 待实测 |
| distance_warning_cm | 一般提醒阈值 | 待实测 |
| distance_safe_cm | 安全距离阈值 | 待实测 |
| approach_rate_threshold_cm_s | 接近速度判定阈值 | 待实测，当前传感器不支持测速 |
| vibration_levels | 振动等级与占空比 | 待实测 |
| vibration_patterns | 振动节奏模式 | 待实测 |
| speech_interval_ms | 同类提示最小间隔 | 待实测 |
| speech_priority | 语音优先级顺序 | 待实测 |
| ultrasonic_timeout_ms | 超声波超时 | 待实测 |
| ultrasonic_retries | 超声波重试次数 | 待实测 |
