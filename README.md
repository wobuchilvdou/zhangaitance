# zhangaitance — ESP32-S3 Blind Assist

一个面向小腿穿戴的辅助设备工程：本地完成超声波测距、危险分级、语音提示和振动提醒，后续扩展云端 AI 识别与紧急求助。

## 当前阶段

阶段 1：本地感知闭环（硬件无关骨架 + 模拟测试）。

- 主控：ESP32-S3-DevKitC-1，模组 ESP32-S3-WROOM-1-N16R8
- 测距：RCWL-1605 超声波，精度待更换，暂不支持测速
- 振动：738 马达模块，MOS 管高电平触发，5V，支持 PWM
- 语音：预录音播放
- 无 IMU，无摄像头，无下视传感器

## 目录

- firmware/: ESP32-S3 固件源码
- simulator/: 硬件无关的模拟与测试
- docs/: 硬件表、阈值配置与测试记录
- scripts/: 构建、烧录与日志脚本

## 阶段 1 范围

1. 距离分级与危险等级
2. 振动节奏与强度控制
3. 语音提示队列与优先级
4. 配置化阈值
5. 硬件抽象接口

硬件未确认的 GPIO、接口与阈值均标注为阻塞项，不写入默认值。

## 运行测试

在工程根目录执行：

```powershell
python scripts/run_tests.py
```

当前 5 项模拟测试已通过，覆盖四个距离等级和非法输入。
